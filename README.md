# Fusion Design 共享视觉资源

本分支维护跨成果视觉参考，以及可选的风格/配色预设、组件配方与预览素材、UI/UX Pro Max 检索数据，不包含插件安装包或项目 Demo。主代码分支保留方法、小型目录与锁定的资源提交号；实际图片由检索脚本按需取用并核对 SHA-256。

当前整理包含 106 张非 UI 视觉参考。每张图片可按构图、风格、材质、字形、配色和图形检索；原作日期、作者或授权未知时，以目录记录为准，不把学习参考视为可直接复用的生产资产。完整 UI 参考沿项目需要在线查找。

- `visual-reference-library/catalog.json`：多维标签、观察、适用边界与图片哈希。
- `visual-reference-library/images/`：实际图片，每个内容哈希仅存一份。
- `visual-reference-source.json`：原始收录与排除记录。
- `resource-manifest.json`：资源版本的文件哈希与体积。

新增资源先看原图、去重并标注可借部分，再同步目录和资源清单。资源提交完成后，由主代码分支更新锁定提交与小型索引；运行时不随分支 HEAD 漂移，也不克隆完整仓库。

## 按需预设与数据

`libraries/` 保存可选库，`library-manifest.json` 记录每个库的文件、字节数与哈希。主代码分支只保留方法、执行工具和小型目录；列出和筛选目录不下载整库，查看、导出、复制或运行对应数据检索时才获取所需文件。组件预览只取得所选组件的依赖与图片。核心执行引擎继续随主包分发。
